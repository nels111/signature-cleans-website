## Conventions
- Navigation and footer are duplicated in every HTML file (no templating)
- CMS editable content marked with `<!-- editable:field_name -->` comments
- Admin tags marked with `<!-- ADMIN-TAG -->` comments
- Blog posts generated by admin.js and written as static HTML files
- Forms submit to Express API endpoints, no client-side framework
